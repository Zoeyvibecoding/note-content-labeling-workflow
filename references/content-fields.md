# 内容字段、来源与生成方式

## 共同数据字段

| 字段 | 来源 | 生成方式 |
|---|---|---|
| 分析对象/角色 | 用户输入 | 记录本品或竞品及对象名称 |
| SPU name | 用户输入＋Excel | 精确匹配并保留原值 |
| nick name 命中 | 用户输入＋Excel | 记录实际命中的别名，不用于代替笔记 ID |
| 消耗排名 | Excel | 在对应对象、对应媒介池内按竞价运营消耗降序生成 |
| 笔记ID | Excel | 作为唯一主键，按文本保存 |
| 跳转链接 | 笔记ID | 生成 `https://www.xiaohongshu.com/discovery/item/{note_id}` |
| 作者/发布时间 | Athena | 按 ID 核验后读取 |
| 竞价运营消耗等投放指标 | Excel | 原值映射，不默默求和或换单位 |
| CTR | Excel 指标 | 公式 `点击量/曝光量`，除零保护 |
| CPTI | Excel 指标 | 公式 `竞价运营消耗/新增TI人群`，除零保护 |
| CPUV | Excel 指标 | 公式 `竞价运营消耗/站外活跃UV`，除零保护 |

## 视频过程字段

| 字段 | 来源 | 生成方式 |
|---|---|---|
| Athena标题/正文 | Athena | 按笔记 ID 读取并保留原文 |
| 视频媒体来源 | Athena | 记录可回溯媒体地址或资产标识 |
| ASR追溯文本（自动转录） | 完整视频音轨 | 保留原始自动转录，按时间顺序，不用正文补齐 |
| ASR质量说明 | ASR＋人工复核 | 记录无语音、错词、重叠音、不可可靠恢复段 |
| 视频花字/OCR | 完整视频画面 | 按时间点记录字幕、花字和包装文字 |
| 首屏承诺 | 开头画面＋ASR/OCR | 概括前 10 秒提供的点击/留存理由，不提前写成产品总结 |
| 一句话总结 | 完整视频事实 | 30–60 字写“人物/场景入口 → 全片如何展开 → 产品扮演什么角色” |
| 视频内容结构 | 完整时间轴 | 写明开头、展开、转场、产品首次出现、产品讲解、结尾 |
| 关键口播 | ASR 或真实花字 | 选择最能代表目标产品卖点、主张、用法、效果或结论的连续原话 |
| 关键口播来源 | ASR/OCR | 精确到 ASR 起止秒或花字帧/时间点 |
| 主场景 | 完整视频 | 识别真正组织全片的生活、任务、人物或产品场景 |
| 产品首次出现 | 完整视频 | 记录首次实际出镜或实质讲解时间点 |
| 产品讲解段 | 完整视频 | 记录主要时间段及每段作用 |
| 产品讲解占比 | 时间轴 | 产品实质讲解秒数/总时长，注明估算置信度 |
| 品牌及产品露出 | 画面＋ASR/OCR | 列出产品实例、实际参与证据和内容角色 |
| 内容证据 | 完整视频 | 只保存能支撑内容事实和打标的可回溯证据 |
| 复核说明 | 全链路 | 记录低置信度、媒体缺失、ASR/OCR 限制及处理方式 |

### 视频关键口播门槛

- 不得来自话题标签、标题、Athena 正文、评论或模型改写。
- 不得选择生活开场、泛价值观或明显 ASR 乱码。
- 只允许修正明确的品牌词、产品词、专业词、同音词、断句和标点。
- 若原句无法可靠恢复，继续检查真实花字或包装文字；不得编造。

## 图文过程字段

| 字段 | 来源 | 生成方式 |
|---|---|---|
| Athena标题/正文 | Athena | 按笔记 ID 读取并保留原文 |
| 图片数 | Athena | 记录实际加载并完成复核的图片数量 |
| 全部图片OCR/视觉证据 | 全部图片 | 按图片 1、图片 2……记录花字、主体、产品和关键视觉证据 |
| 首图承诺 | 封面/图片1 | 概括首图吸引点击的主题与承诺 |
| 一句话总结 | 正文＋全部图片 | 30–100 字写“内容入口 → 展开方式 → 产品角色” |
| 图文内容结构 | 正文＋全部图片 | 生成“钩子 → 展开 → 产品承接 → 证据 → 收束”，每段对应真实内容 |
| 品牌及产品露出 | 正文＋全部图片 | 列出品牌、产品、图片序号/正文证据和内容角色 |
| 关键文案 | Athena正文或图片花字 | 选择最能代表目标产品卖点、主张、用法、效果或结论的连续原句 |
| 关键文案来源 | Athena/图片 | 标明 `Athena正文` 或具体 `图片N` |
| 主场景 | 正文＋全部图片 | 识别真正组织内容的观点、身份、任务、日常或产品场景 |
| 内容证据 | 正文＋全部图片 | 保存支持事实和标签的原句或图片序号 |
| 复核说明 | 全链路 | 记录图片缺失、OCR 失败、正文与图片冲突或低置信度 |

### 图文关键文案门槛

- 必须逐字可回溯，不得拼接不连续句、润色或概括后冒充原话。
- 横测优先比较/选择结论，促销优先购买机制，组合优先搭配/步骤，单品优先核心主张或结果证据；这只是候选优先级，不是固定模板。
- 正文已建立唯一产品语境时，候选句无需重复品牌名，但来源和连续原文必须保留。
- 标题只有在它本身也是正文或图片中的真实产品文案时才可引用；不得用标题兜底空字段。
