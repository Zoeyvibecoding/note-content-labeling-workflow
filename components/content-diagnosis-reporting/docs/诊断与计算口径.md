# 诊断与计算口径

## 1. 数据排除

- 缺失、非数字、负值记为错误或无效值。
- 分子或分母为 0 的笔记不进入对应指标；不影响其他指标。
- CPTI、CPUV 先计算单篇成本，再在每个 SPU 内按配置的 IQR 倍数识别极端值，默认 `Q1 - 1.5×IQR` 至 `Q3 + 1.5×IQR`。被剔除笔记仍计入笔记数和结构消耗，但不进入对应效率指标。
- 每次剔除都写入 `metric-exclusions.json`，不得静默删除。

## 2. 加权指标与 Bench

- CTR、CPTI、CPUV 均为有效样本底层分子之和÷分母之和。
- 子类、大类、本品、竞品和本品+竞品同池 Bench 使用同一函数。
- 同池 Bench 是该指标在指定比较池内的汇总值，不为每个子类另造一个“Bench 列”。
- CTR 越高越好；CPTI、CPUV 越低越好。
- 本品子类明细表的颜色只对比“本品整体 Bench”：CTR 高于 Bench 标绿、低于标红；CPUV/CPTI 低于 Bench 标绿、高于标红；相等或无有效值保持中性色。不得使用竞品或本品+竞品同池 Bench 为本品子类着色。
- 子类明细结论按“大类比较 → 美垂四子类内部差异 → 破圈四子类内部差异”递进，两个大类内部都必须点出具体表现及数字，禁止只分析其中一类。
- 相邻板块之间只允许一个分页/分隔元素；输出前检查连续分隔符，并避免在同一边界同时使用显式分隔符和 CSS 强制分页。

## 3. 高优候选

- 默认要求三个指标都有有效值，并至少两个指标优于“同品牌、同子类”Bench：本品只与本品同子类比较，竞品只与竞品同子类比较。
- 高优是进入内容归纳的候选条件，不等于内容公式。
- 0 值或对应指标极端值笔记不得作为公式样本。

## 4. 内容公式

内容公式的判断主链为：`认知起点 → 意义转化机制 → 产品结论 → 可信性闭环`。报告固定压缩为：`选题切口 + 使用场景 + 叙事过程 + 产品角色 + 效果证明`。

每条公式至少由同品牌、同子类两篇双指标或三指标高优笔记支持，而且两篇都必须出现同一条完整的意义转化关系。共同出现成分、人设、场景、产品词或话题词，只能作为表面共性，不能直接归纳为公式。只有单篇支持的内容只能称为观察；重复出现但缺少两篇有效高优后链路的机制，只能称为“高频候选公式”。

竞品独占/共有/本品独占判断看叙事机制是否出现及是否形成多样本，不把单纯的指标更优误写成内容独占。认知起点、因果关系、产品意义和证明方式必须能回溯到标题、正文、ASR、OCR、总结或证据字段，不得补写。

## 5. 样本标题

- 样本卡只使用小红书真实标题，完整保留标点、空格、符号与 emoji，禁止 AI 改写。
- 回退顺序：过程文件标题 → 原笔记 `og:title` → 页面 `<title>`（仅去平台后缀）→ 笔记 ID。
- 标题缺失时先运行 `node src/resolve-titles.mjs --config <config>`；若网页直接请求受限，则通过浏览器读取原链接并人工写入 `output/title-overrides.json`。
- 报告生成前校验样本标题与已解析标题完全一致，不一致即停止生成。

## 6. Action List

每项必须包含：动作、适用内容、执行方式、验收标准。验收标准使用下一轮可计算的结构占比、CTR、CPTI、CPUV、高优样本数或内容要素完成率，避免空泛建议。
