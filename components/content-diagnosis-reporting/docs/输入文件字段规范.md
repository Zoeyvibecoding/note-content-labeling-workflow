# 输入文件字段规范

## 文件形态

- 一个 SPU 一个 `.xlsx` 文件，不把不同 SPU 合并在同一工作簿。
- 每个工作簿至少包含 `视频笔记理解`、`图文笔记理解` 两张表；没有某媒介时允许保留只有表头的空表。
- 默认表头在第 3 行，可在配置中修改。
- 每行是一篇笔记；`笔记ID` 在一个 SPU 内唯一。
- 本品/竞品身份不写死在工作簿里，由 `analysis-config.json` 指定。

## 所有笔记必需字段

| 字段 | 类型 | 作用 |
|---|---|---|
| 笔记ID | 文本 | 唯一键与证据追溯 |
| 跳转链接 | URL/文本 | 案例回看 |
| Athena标题 | 文本 | 案例标题与叙事证据 |
| Athena正文 | 文本 | 内容诊断证据 |
| 一句话总结 | 文本 | 内容机制摘要 |
| 笔记类型 | 文本 | 必须为视频或图文，亦可由工作表推断 |
| 打标标签 | 文本 | 子类标签 |
| 打标原因 | 文本 | 标签判定依据 |
| 内容证据 | 文本 | 可直接回溯的原文/画面/口播证据 |
| 反事实检验 | 文本 | 排除邻近标签的检验 |
| 最邻近标签 | 文本 | 边界复核 |
| 排除原因 | 文本 | 排除邻近标签的原因 |
| 置信度 | 数值/文本 | 0–1、百分比或高/中/低 |
| 复核标记 | 文本/布尔 | 是否需要人工复核 |
| 内容来源 | 文本 | 数据来源说明 |
| 理解状态 | 文本 | 必须能判断为已完成 |
| 打标规则版本 | 文本 | 标签字典版本追踪 |

允许的子类标签：`促销机制、同类横测、多品组合、单品主导、观点价值、身份阶段、场景任务、日常生活`。历史名称如“护肤方案 / 多品组合”“单品种草”必须在配置别名中显式映射，不得临时猜测；“待媒体复核”说明打标尚未完成，必须返回上游处理，不能进入诊断。

## 指标计算必需字段

| 指标 | 必需原始字段 | 公式 | 缺失后果 |
|---|---|---|---|
| CTR | 曝光量、点击量 | Σ点击量 ÷ Σ曝光量 | 阻断 CTR 及依赖它的高优判断 |
| CPTI | 竞价运营消耗、新增TI人群 | Σ竞价运营消耗 ÷ Σ新增TI | 阻断 CPTI 及依赖它的高优判断 |
| CPUV | 三方消耗、站外活跃UV | Σ三方消耗 ÷ Σ站外活跃UV | 阻断 CPUV 及依赖它的高优判断 |

`CTR、CPTI、CPUV` 成品列可以存在，但仅用于核对，不能替代底层字段。`竞价运营消耗` 不能代替 `三方消耗`。

## 视频笔记必需理解字段

`ASR追溯文本（自动转录）、ASR质量说明、首屏承诺、关键口播、关键口播来源、主场景、产品讲解占比`。

这些字段确保内容公式真正覆盖视频画面/口播，不退化为只读标题和正文。

## 图文笔记必需理解字段

`图片数、图文内容结构（原字段）、结构化内容路径、品牌及产品露出、关键文案、关键文案来源`。

## 推荐增强字段

- `封面URL` 或 `封面本地路径`：用于报告笔记卡封面；缺失只警告，不阻断统计。
- `作者、发布时间、消耗排名、互动量、新增I人群`：增强案例解释与核对。
- `内容大类`：可选；如存在，必须与子类映射一致。

## 固定大类映射

- 美垂：促销机制、同类横测、多品组合、单品主导。
- 破圈：观点价值、身份阶段、场景任务、日常生活。

## 最小外观示例

见 `examples/video-sheet-example.csv` 与 `examples/image-sheet-example.csv`。CSV 只用于说明表头和一行长什么样，正式输入仍为一个 SPU 一个 XLSX。
