# 真实文件反向校验记录

本包开发时使用以下两份现有工作簿做了只读校验：

- 伊菲丹面霜：视频 100 篇、图文 100 篇。
- 兰蔻菁纯面霜：视频 100 篇、图文 100 篇。

读取器成功读取 400 篇笔记，并识别出以下需要由上游新版本补齐的问题：

1. 两个 SPU 的视频、图文表均没有独立的 `三方消耗` 字段，因此不能按已确认口径重算 CPUV；现有 `竞价运营消耗` 不可替代。
2. 存在 `待媒体复核`，这类记录不是最终打标结果，必须在上游完成复核。
3. 存在历史标签名称 `护肤方案 / 多品组合`、`护肤方案/多品组合` 和 `单品种草`；可通过配置中的显式别名映射到现行标签。
4. 兰蔻文件缺少若干必须保留的理解证据字段，例如视频的 Athena 标题/正文、ASR 追溯文本、首屏承诺、主场景，以及图文的内容结构与路径字段。
5. 两份文件均无封面字段；不会阻断统计，但内容公式卡无法露出真实封面。

这份记录说明校验器不是以“能打开 Excel”为通过条件，而是检查后续诊断是否真的拥有同口径数据和完整证据。上游 AI 产出符合《输入文件字段规范》的新文件后，才应进入报告生成。
